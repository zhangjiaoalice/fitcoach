📋 交互逻辑说明

触发时机

  • 用户 register 成功 → 后端返回 profile_completed: false
  • 前端 router guard 判断：没完成画像 → 强制跳 /onboarding，不能访问 /chat /me 等页
  • 完成后调 PATCH /users/me/profile，后端标记 profile_completed: true → 跳 /dashboard
  • 用户想修改时从 /me → 画像设置 → 可以重新进入，但不强制

各步校验

  • Step 1：昵称 2-20 字 + 性别必选 + 年龄 14-80
  • Step 2：身高 100-220cm + 体重 30-200kg；目标体重 ±30% 当前体重，防止极端值
  • Step 3：目标 + 频率必选；饮食偏好可空
  • 按钮状态：未满足字段 → .btn-disabled 置灰；满足 → 蓝色高亮

键盘体验（移动端细节）

  • 昵称输入：enterkeyhint="next"，回车直接跳下一个字段
  • 数字字段：inputmode="decimal" 调出数字键盘，不要 iOS 全键盘
  • stepper 按住 +/− 长按连加（≥ 500ms 启动 50ms 节流）
  • 页面避免 keyboard 弹出遮挡：主体内容加 padding-bottom: 48vh on focus

动画细节

  • 进度条当前段：pulse 呼吸动画
  • 选项卡被选中：transform: scale(1.02) + 阴影加深
  • 完成页：6 个 emoji confetti 下落 + Momo 居中出现 + 底部按钮延迟 0.5s 淡入
  • "开始冒险" 点击：confetti 加速 + 跳转 /dashboard

Vue 组件拆分建议

  • OnboardingLayout.vue — 顶栏进度条 + Momo 对白 + 底部按钮壳
  • OnboardingView.vue — 主视图，用 v-if currentStep 切换 3 个 StepXxx
  • StepIdentity.vue / StepBody.vue / StepGoal.vue
  • OnboardingSuccess.vue — 完成庆祝 + 跳转
  • 状态存 Pinia store useOnboarding()，提交时一次性 PATCH
