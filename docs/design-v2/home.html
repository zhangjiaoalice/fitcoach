📋 改版说明

致敬 Keep 的核心模式

模块Keep 原设计FitCoach 改造
顶部日期切换◀ 今日 ▶ 居中药丸保留，色调调成米白底
顶部评分饮食评分半环 + 大数字保留 + emoji 情感化（🥗 😋 🔥）
营养状态条偏低 / 偏高 / 不足保留 + 加「达标」绿色状态
AI 洞察卡紫色 ✨ 图标保留 + 嵌入 Momo 头像 + 「去问 Momo」按钮（直连 Chat）
热量仪表盘摄入 / 还可摄入 / 消耗保留，用 Duolingo 色对应
营养成分进度条横条 + 环形占比保留，碳水橙/蛋白绿/脂肪蓝
饮水水瓶插画 + 大数字保留 + 加8 格杯子条（更游戏化）
减重计划广告位橙色 Banner去掉（Momo 浮动 CTA 已经承载了引导作用）
添加数据按钮底部绿色大圆角保留 + 左侧挂 Momo 浮球（点 Momo 直通 Chat）

FitCoach 独有的差异化

  • Momo 浮动 CTA：底部按钮左侧有一个 Momo 圆球，点她直接跳 /chat（Keep 没有 AI 教练入口，这是我们的核心差异点）
  • AI 洞察卡集成 Momo：Keep 的 AI 洞察是冷冰冰文字，我们加头像 + 第一人称台词 + 「去问 Momo」直通按钮
  • 营养状态加「达标」：Keep 只有负向标签（偏低/偏高/不足），我们加正向反馈让用户有成就感
  • 8 格杯子条：饮水视觉化到杯子级，比 Keep 的"大数字 + 水瓶图"更有游戏感
  • 空状态引导：新用户看到 Momo + 「去问 Momo」而不是"开启减重计划"广告

字段映射（对接 FitCoach 后端）

  • 顶部评分：按营养均衡度 + 热量达标度算权重，具体公式后端定
  • 饮食摄入 / 运动消耗：GET /diet-logs/today + GET /workout-logs/today 求和
  • 推荐摄入：GET /profile 返回的 TDEE × 目标系数（减脂 0.85 / 增肌 1.1 / 塑形 1.0）
  • 碳水/蛋白质/脂肪克数：diet-logs 每条带 nutrition，服务端 aggregate
  • AI 洞察文案：新接口 GET /insight/today，后端调 LLM 生成（可以每天只调 1 次缓存）
  • 饮水：新 model water_logs 需要加（当前后端没有，M3 没覆盖）

组件拆分建议（Vue）

  • HomeView.vue（主容器）
  • DateSwitcher.vue（日期切换）
  • DietScoreCard.vue（顶部评分 + 营养状态条）
  • AiInsightCard.vue（AI 洞察 + Momo 引导）
  • CalorieGauge.vue（热量仪表盘，复用 Keep 的三栏布局）
  • NutrientCard.vue（碳水/蛋白/脂肪进度 + 饼图）
  • WaterCard.vue（饮水杯子条）
  • FloatingCta.vue（Momo 浮球 + 添加按钮）

落地路线图

  • P0 优先：日期切换 + 热量仪表盘 + Momo 浮动 CTA（骨架先搭）
  • P1：营养成分卡（含饼图） + AI 洞察卡 → 后端需补 insight 接口
  • P2：饮水 → 后端需加 water_logs model
  • P3：顶部评分算法 → 需要定义评分公式
