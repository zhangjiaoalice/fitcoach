设计原则

  • 粗描边 + 厚底阴影（box-shadow: 0 4px 0 color）—— 卡通质感来源，按下有物理反馈
  • 圆角一致（卡片 16px、按钮 16px、徽章 999px）—— 柔软友好
  • 强对比色（蓝/绿/黄作主，粉/紫作点缀）—— 保持活力但不杂乱
  • 吉祥物无处不在（头像/空状态/成就页）—— 建立品牌记忆（主角：Fit Momo 女教练 💪 + Fit Hero 男教练 🔥，原创日系卡通形象，用户可自选）
  • 游戏化反馈（XP / 连击 / 徽章 / 关卡）—— 鼓励坚持
  • 8pt 间距系统（8/12/16/20/24）—— 节奏统一
